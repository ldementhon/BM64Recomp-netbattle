Bomberman 64 Recompiled - online Battle test build (Mac, Apple Silicon only)

1. Unzip, then in Terminal run this once from this folder so macOS lets the app open:
   xattr -dr com.apple.quarantine BM64Recompiled.app
   Then open BM64Recompiled.app.
2. The first time, select your own Bomberman 64 (USA) ROM in .z64 format.
   Its SHA-256 must be:
   e6da7c26127788cd894b88b71cc055ff9dec0d0f4f8e10d9b15b40153af2b52a
   (check it in Terminal with: shasum -a 256 "path/to/rom.z64")
3. Online Battle -> enter the server address and port you were given, a name,
   pick your controls, then Ready.

Don't replace or rebuild the app: the server only accepts this exact build.

The launcher shows this download's online version in its bottom-left corner
(for example "Online v1"). Everyone in a match needs the same version as the server.
